# 01. 요구사항 정의서 (Requirements)

## 1) 목표
- 추세추종/매크로/가치/리스크관리 원칙을 실행 가능한 운영 시스템으로 구현
- 일관된 룰 실행으로 감정 개입 감소
- 최대낙폭(MDD) 통제를 최우선 KPI로 운영

## 2) 범위 (MVP)
- 룰 기반 진입/청산 엔진
- 포지션 사이징 엔진(고정 % 리스크, ATR 기반)
- 손실 중단 규칙(일/주)
- 트레이드 저널 자동 기록
- 일/주/월 리뷰 리포트

## 3) 제외 범위 (MVP 외)
- 초저지연 HFT
- 대체데이터 기반 초고빈도 신호
- 브로커사별 복잡 주문 라우팅 최적화

## 4) 기능 요구사항
- FR-01: 전략 룰 템플릿 등록/수정/버전관리
- FR-02: 진입 전 필수 체크(셋업 일치, 손절가, R:R)
- FR-03: 주문 시 손절/익절 동시 설정(OCO 가능)
- FR-04: 손실 한도 도달 시 신규 진입 차단
- FR-05: 거래별 저널(근거/규칙위반/결과R) 자동 저장
- FR-06: 주간 성과 리포트(승률, 손익비, 기대값, MDD)

## 5) 비기능 요구사항
- NFR-01: 장애 시 포지션/리스크 상태 복구 가능
- NFR-02: 모든 의사결정 로그 추적 가능(audit)
- NFR-03: 설정값 변경 이력 저장
- NFR-04: 수수료/슬리피지 반영 가능

## 6) 사용자 역할
- Trader: 전략 실행/중지, 리스크 한도 설정
- Reviewer: 성과 검토, 규칙 위반 분석
- Admin(옵션): API 키/운영 환경 관리
