# 06. 90일 구현 로드맵

## Phase 1 (Day 1~30) — 생존 시스템
- 전략 1개 선정 및 룰 문서화
- 리스크 엔진(1회/일/주 한도) 구현
- 백테스트 + 비용(수수료/슬리피지) 반영
- 완료 기준: 규칙 준수율 측정 가능, Kill Switch 동작

## Phase 2 (Day 31~60) — 실행 품질
- 실거래(소액) 또는 페이퍼트레이딩 연동
- 자동 저널 + 위반 탐지 구현
- 주간 리포트 자동화
- 완료 기준: 위반 거래율 감소, 손실 중단 규칙 정상 작동

## Phase 3 (Day 61~90) — 포트폴리오화
- 보조전략 1개 추가(상관 낮은 전략)
- 포지션 사이징 자동화 고도화
- 월간 리스크 재조정 로직 반영
- 완료 기준: 전략별 성과 분해 + MDD 관리 체계 확립
