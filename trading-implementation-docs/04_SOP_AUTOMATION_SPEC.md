# 04. SOP 자동화 명세

## 1) 일간 SOP
### 프리마켓(20~30분)
- 이벤트 캘린더 로드
- 레짐 분류 실행
- 오늘 리스크 한도 설정
- 감시 종목/자산 리스트 생성

### 장중
- 진입 전 체크리스트 자동 검증
- 주문 시 손절/익절 자동 동시 등록
- 손실 중단 조건 트리거 시 신규진입 차단

### 마감 후
- 거래 로그/스크린샷/근거 자동 저장
- 위반 여부 라벨링
- 규칙 준수율 계산

## 2) 주간 SOP
- 주간 KPI 리포트 생성
- 손실 거래 리플레이 큐 생성
- 상위 셋업 유지/하위 셋업 제거 추천

## 3) 월간 SOP
- 전략별 기대값 재계산
- MDD/변동성 기반 리스크 % 재조정 제안
- 월간 중단 규칙 검증

## 4) 알림 정책
- 경고: 일간 손실 70% 도달
- 차단: 일간 손실 100% 도달
- 리뷰: 주간 손실 중단 발생 시 다음 주 자동 리스크 축소 제안
