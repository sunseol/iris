# 트레이딩 운영 고도화 - 개발 구현 문서

이 문서는 실수익 트레이더들의 공통 원칙(리스크 관리, 포지션 사이징, 규칙 기반 실행)을 **실제 구현 가능한 시스템**으로 옮기기 위한 개발 문서 묶음입니다.

## 문서 목록
1. `01_REQUIREMENTS.md` — 목표, 범위, 비기능 요구사항
2. `02_SYSTEM_ARCHITECTURE.md` — 모듈 구조/데이터 흐름/기술 스택
3. `03_TRADING_RULE_ENGINE_SPEC.md` — 전략·리스크 룰 엔진 스펙
4. `04_SOP_AUTOMATION_SPEC.md` — 일/주/월 SOP 자동화 명세
5. `05_RISK_POLICY_AND_LIMITS.md` — 리스크 한도 정책(1천만~5천만원)
6. `06_90DAY_IMPLEMENTATION_ROADMAP.md` — 90일 개발/검증 로드맵
7. `07_TEST_PLAN_AND_METRICS.md` — 테스트 계획과 KPI

## 핵심 원칙
- **생존 우선:** 손실 제한 > 수익 극대화
- **사이징 우선:** 진입 신호보다 포지션 크기 통제가 성과에 더 큰 영향
- **규칙 우선:** 임의 판단 최소화, 자동화 가능한 형태로 문서화
- **검증 우선:** 백테스트 + 워크포워드 + 소액 실거래 단계적 전환

## 전제
- 투자 권유가 아닌 시스템 설계 문서
- 시장별(코인/국내주식/해외선물) 어댑터는 별도 플러그인으로 분리
