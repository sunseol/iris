# 07. 테스트 계획 및 성과 지표

## 1) 테스트 레벨
- Unit: 사이징 계산, 손실 한도 계산
- Integration: 신호→리스크→주문 파이프라인
- Replay: 과거 데이터 재생으로 주문/중단 규칙 검증
- Dry-run: 실시간 데이터 기반 무체결 모드

## 2) 핵심 KPI
- Expectancy(E)
- Profit Factor
- Max Drawdown(MDD)
- 규칙 준수율(%)
- 평균 손익비(R multiple)

## 3) 합격 기준(예시)
- MDD가 정책 임계 이하
- 규칙 준수율 90% 이상
- 슬리피지/수수료 반영 후 Expectancy > 0

## 4) 운영 리스크 시나리오
- 거래소 API 지연/오류
- 가격 급변(갭)으로 손절 미체결
- 중복 주문/네트워크 재전송
- 데이터 결측/이상치

각 시나리오마다 대응 플로우(차단/재시도/수동개입)를 Runbook으로 별도 유지.
