After code changes in this repo, prefer running from `opencode-mobile/`: `npm run lint`, `npm run build`, and `npm run test`, or `npm run gate` for the full sequence. On Windows, verify bridge tests carefully because `bridge/src/session-store.js` currently uses URL pathname handling that breaks absolute Windows paths, and `bridge/tests/cancel-native.test.js` also uses `sleep`, a Unix-specific command. For runtime/manual verification, use `app` Expo commands and the bridge stub/process modes documented in `BETA.md` and `EMULATOR_REGRESSION_MATRIX.md`.
