OpenCode Mobile is a small npm-based monorepo under `opencode-mobile/` with two packages: `app/` (Expo React Native mobile client) and `bridge/` (Node WebSocket bridge). Root `package.json` orchestrates `lint`, `build`, `test`, and `gate` across both packages using `npm --prefix`. Important docs: `README.md`, `BETA.md`, `EMULATOR_REGRESSION_MATRIX.md`, `RECOVERY.md`, and `deploy/DEPLOYMENT.md`. Windows development is possible, but some bridge tests currently assume Unix-like path/process behavior.
