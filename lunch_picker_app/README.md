# lunch_picker_app

점심 메뉴를 랜덤으로 추천해주는 간단한 Flutter 앱입니다.

## 기능
- 기본 메뉴 목록 제공
- 메뉴 직접 추가/삭제
- 랜덤 버튼으로 오늘 점심 추천

## 실행 방법
> 이 환경에는 Flutter SDK가 설치되어 있지 않아 실행은 못 했습니다.

1. Flutter 설치
2. 프로젝트 폴더 이동
   ```bash
   cd lunch_picker_app
   ```
3. 패키지 설치
   ```bash
   flutter pub get
   ```
4. 실행
   ```bash
   flutter run
   ```
