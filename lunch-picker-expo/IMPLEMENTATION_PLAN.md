# Lunch Picker App 고도화 구현 계획

## 목표
현재 위치 기반 추천 앱을 실사용 가능한 개인화 추천 앱으로 확장한다.

## Phase 1 (바로 시작)
1. 로컬 데이터 레이어 도입 (AsyncStorage)
   - 즐겨찾기/비선호
   - 최근 추천 히스토리
   - 사용자 설정(예산, 중복제외 일수, 자동새로고침 여부)
2. 추천 엔진 v2
   - 최근 n일 제외
   - 좋아요 가중치(+), 비선호 감점(-)
   - 거리/카테고리/검색 반영
3. 필터 UX 확장
   - 예산(가볍게: 저가/중가/고가)
   - 영업중 필터(데이터 소스 가능 범위)

## Phase 2
4. 날씨 연동 추천(Open-Meteo)
   - 비/한파 시 실내/국물류 가중치
5. 그룹 추천 모드
   - 참여자별 태그 선택 -> 교집합 우선
6. 지도 탭(리스트/지도 전환)

## Phase 3
7. 공유 기능
   - 오늘의 추천 카드 이미지/텍스트 공유
8. 운영 안정화
   - 요청 캐시
   - 오류 리포트
   - API 폴백 강화

---

## 지금 착수 항목

- 데이터 모델 및 저장 구조를 먼저 넣고, UI에서 즉시 체감 가능한 설정값을 노출
