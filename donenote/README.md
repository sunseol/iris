# DoneNote

AI meeting and conversation note organizer.

## MVP
- create projects
- paste notes
- analyze into summary + action items
- save history locally
- edge AI preview panel for local extraction hints

## Product direction
DoneNote is moving toward a hybrid AI architecture:
- cloud for final structured analysis
- browser-side preprocessing for privacy and speed
- WebGPU acceleration when available

See `docs/EDGE_AI_ARCHITECTURE.md`.

## Run
```bash
npm install
npm run dev
```
